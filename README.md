# ניצן ביחד — מוקאפ מלא

מוקאפ אינטראקטיבי בעברית וב־RTL. כולל מסכי דיירים, עו״ס/מדריכת דירה ואדמין, תהליך הצטרפות מלא וריאיון בן **12 צעדים**. זו גרסת **הדפדוף בפרופיל**, ולא גרסת הגלילה האנכית.

**[פתיחת המוקאפ](https://yosishe.github.io/nitzan-beyachad-full-mockup/)** · [פרופילים](https://yosishe.github.io/nitzan-beyachad-full-mockup/#profiles) · [הריאיון המלא](https://yosishe.github.io/nitzan-beyachad-full-mockup/#profile-interview) · [עו״ס](https://yosishe.github.io/nitzan-beyachad-full-mockup/#worker-mobile) · [אדמין](https://yosishe.github.io/nitzan-beyachad-full-mockup/#admin-mobile)

## מה כלול

- בית דייר, פרופילים, לייקים, בקשות שהתקבלו, הודעות פתיחה ותצוגה לפני שליחה.
- בפרופיל: תמונה, שם/גיל/עיר, טקסט קצר, תחביבים וסיכום. החיצים עוברים בין חלקי אותו פרופיל; הפעולה למעבר לאדם הבא נפרדת. התמונות והחיצים שומרים על מיקום קבוע.
- כל עמוד פרופיל נכנס למסך בגודל טקסט רגיל ברוחבים שנבדקו: 294, 320, 390 ו־430 פיקסלים. בכתב מוגדל מאפשרים גלילה לפי הצורך כדי לשמור על קריאות ועל כל התוכן. טפסים ורשימות ארוכות נגללים.
- תמונה מוגדלת, הקראה ועזרי קריאה; עיצוב מותאם לסלולרי.
- שיחות עצמאיות ושיחות עם ליווי בשלוש שאלות פתיחה, והדמיית הצעות בהתאם להקשר. בחירת הליווי נעשית יחד עם הדייר/ת והעו״ס.
- דיווח והקפאת שיחה, חסימה, בקשת עזרה, בקשת פגישה והדרכת בטיחות, שיתוף מספרי דוגמה בהסכמה הדדית, הפסקה וחזרה.
- עו״ס/מדריכת דירה היא אותו תפקיד: דיירי העיר המשויכת לה בלבד. אדמין רואה את ארבע הערים: תל אביב, רעננה, הרצליה ומודיעין.
- אישור ותיקון פרופילים, התראות רגילות ודחופות, העדפות SMS מדומות, נתוני שימוש, בקשות עזרה ודיווחים, חיווי שיתוף מספרים וחוסר מענה.
- מכסת הפניות היא לפניות היכרות חדשות. הודעות בשיחה קיימת אינן מוגבלות לשלוש ביום.

## הריאיון — 12 צעדים

חלק א׳: שם/גיל/עיר ומגדר, תמונות, תחביבים, מה עושה לי טוב, העדפות תקשורת והעדפות היכרות.

חלק ב׳: שש שאלות ליצירת „קצת עליי”. בכל שאלה שלוש הצעות למשפטים מלאים ואפשרות לכתוב או לערוך במילים שלי:

1. מה הכי כיף לך לעשות?
2. מה החברים אומרים עליך?
3. מה משמח אותך ביום רגיל?
4. את מי היית רוצה להכיר?
5. מה הייתם עושים יחד בפעם הראשונה?
6. מה עוד חשוב שיידעו עליך?

התשובות מחוברות לטקסט בפרופיל. ניסוח חופשי נשמר כפי שנכתב; הצעת ניסוח אינה מוחלת אוטומטית. אפשר לעצור ולחזור כל עוד הדף פתוח, לחזור לצעד קודם, לראות תצוגה מקדימה, לערוך ולשלוח לאישור הצוות. נתוני הזיהוי מוזנים או מאומתים עם הדייר, ולא נוצרים אוטומטית מתשובות מומצאות.

## מוקאפ ללא בקאנד

כל האינטראקציות פועלות בזיכרון הדפדפן. אין מסד נתונים, חשבונות אמיתיים, שרת אפליקציה, מפתחות API, שליחת SMS או קריאות למודל AI. הבחירות והתצוגות הן הדמיה מקומית; רענון מחזיר לנתוני הדוגמה. מעבר בין צדדים מדגים את אותה שיחה באותו דף — אין סנכרון בין מכשירים או כרטיסיות.

תצוגות התפקידים מדמות הרשאות בלבד; אין כאן אימות או בקרת גישה המתאימים למוצר חי. אין להזין מידע אישי אמיתי. התמונות, המספרים והפרופילים מיועדים להדגמה.

## הפעלה מקומית

נדרש Python 3; לא נדרשת התקנת תלויות להפעלת האפליקציה.

```sh
git clone https://github.com/yosishe/nitzan-beyachad-full-mockup.git
cd nitzan-beyachad-full-mockup
python3 -m http.server 8000 --bind 127.0.0.1
```

פותחים `http://127.0.0.1:8000/`. קבצי התמונה והשמע נכללים במאגר.

| כניסה | כתובת יחסית |
| --- | --- |
| דייר — בית | `/#resident-demo` |
| פרופילים | `/#profiles` |
| ריאיון מלא, כולל פרטי ההצטרפות | `/#profile-interview` |
| שש שאלות קצת עליי | `/#about-questions` |
| בקשות שהתקבלו | `/#requests` |
| שיחות | `/#chats` |
| יעל — שיחה עם עזרה | `/#yael-chat` |

למסלול כניסה ראשונה אפשר להתחיל במסך הכניסה ולבחור את מספר הדוגמה של נועה. קוד האימות המדומה: `2468`.

## קבצים

- `index.html` — האפליקציה המלאה: נתוני הדגמה, מסכים, עיצוב ולוגיקת האינטראקציות.
- `paged-profile.js`, `paged-profile.css` — דפדוף בתוכן הפרופיל והתאמתו למסך.
- `phone-photo.js`, `phone-photo.css` — הגדלת תמונה בגבולות תצוגת הטלפון.
- `resident-photos-v1/`, `resident-photos-v1.js`, `pictures-0b4a83f6c1.js` — כל נכסי התמונות.
- `audioClips-fc76460235.js` — קטעי שמע להדגמה. הקראת טקסט נוסף תלויה בקולות הזמינים בדפדפן.
- `SOURCE.json` — מקור הגרסה וגיבובי SHA-256 של קובצי האפליקציה.
- `tests/check_demo.py` — בדיקת דפדפן חוזרת להפעלה מקומית או נגד האתר הציבורי.

## בדיקות

```sh
python3 -m venv .venv
.venv/bin/pip install -r tests/requirements.txt
.venv/bin/python -m playwright install chromium webkit
.venv/bin/python tests/check_demo.py --url http://127.0.0.1:8000 --engine chromium
.venv/bin/python tests/check_demo.py --url http://127.0.0.1:8000 --engine webkit
```

הבדיקה מכסה את כל הפרופילים וחלקיהם בכמה רוחבי מסך, מיקום החיצים, הגדלת תמונה, ריאיון בן 12 צעדים, הצעות ותשובה חופשית, בניית הטקסט, שליחה ואישור צוות, חזרה מפרופיל לשיחה עם שמירת טיוטה וכניסות לתפקידי הצוות. אינה תחליף לבדיקות מוצר עם דיירים או לבדיקת כל מצבי המוקאפ.
